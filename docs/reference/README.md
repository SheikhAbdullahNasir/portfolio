# Reference material from the design phase

These files are references, not production code. Rewrite cleanly when building.

- `globe.js`: the hero globe (Canvas 2D, no dependencies). Behaviour to keep: dotted sphere, Karachi pin with pulse, arcs to cities with moving dots, gentle sway, cursor tilt (desktop) or drag (touch), pause when hidden, still frame for reduced motion.
- `melt-test.html`: the melt effect on the name. Open it in a browser to feel it. Defaults are Abdullah's picks (Melt 7, Pull 0.15).
- `assets/docscout-issue.jpg`: real DocScout screenshot (a labeled issue card), cropped, no private text. OK to use.
- `assets/docscout-home.jpg`: real DocScout home page, cropped. **Replace before launch**: the word "next" has an accidental blue text selection on it.

The full set of prototypes (all directions, palette, navbar options, stacking cards, full page, round 5 interactions) lives on a private Claude Design canvas named "Portfolio V2 Directions" in Abdullah's Claude account. Ask him for screenshots if a detail is unclear.
